# PDF Slide Presenter

> Turn any PDF presentation into an interactive, Google Slides–style presentation experience directly in your browser.

**PDF Slide Presenter** provides a presenter-first experience for PDF slide decks exported from PowerPoint, Keynote, Canva, Figma, or Google Slides. No sign-ups, and zero cloud uploads.

---

## Key Features

- **Fullscreen Slideshow Mode:** Dedicated presentation mode equipped with a live presenter timer, slide counter, and click-to-advance navigation.
- **100% Private & In-Browser:** Rendered locally via `pdf.js`. Presentations are cached in your browser's IndexedDB so they survive page refreshes without ever leaving your machine — ideal for confidential company decks.
- **Zero Latency:** Opens decks of any size in 0ms with no network upload wait.

---

## Presentation Controls

| Action | Shortcut / Control |
| :--- | :--- |
| **Next Slide** | <kbd>→</kbd> <kbd>↓</kbd> <kbd>Space</kbd> <kbd>PageDown</kbd> or screen click |
| **Previous Slide** | <kbd>←</kbd> <kbd>↑</kbd> <kbd>PageUp</kbd> |
| **First / Last Slide** | <kbd>Home</kbd> / <kbd>End</kbd> |
| **Toggle Filmstrip** | <kbd>S</kbd> or filmstrip icon |
| **Start Slideshow** | Click **Slideshow** button |
| **Exit Slideshow** | <kbd>Esc</kbd> or close button |
